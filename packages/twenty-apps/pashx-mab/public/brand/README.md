# PxD application logo

`pxd-logo-512.png` is the bundled PxD application mark derived from Shahil's supplied
`Pashxd-logo2.jpg`. It is included in the application manifest so the installed application does
not display a Twenty or generic placeholder mark and does not depend on an external asset host.

`mab-indus-solutions-logo.jpg` is Shahil's supplied MAB Indus Solutions tenant mark. It appears in
the Command Centre welcome treatment and on the installed application's secondary navigation tile,
while PxD remains the main product identity.
