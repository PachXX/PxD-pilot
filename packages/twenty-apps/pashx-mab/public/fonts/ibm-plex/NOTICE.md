# IBM Plex font assets

The WOFF2 files in this directory come from the official
[`IBM/plex`](https://github.com/IBM/plex) repository at commit
`bf260093582f04622aacc1e9f9ca604d7ccd0c42`.

Included weights:

- IBM Plex Sans Regular (400) and SemiBold (600)
- IBM Plex Sans Arabic Regular (400) and SemiBold (600)
- IBM Plex Mono Regular (400)

They are distributed under the SIL Open Font License 1.1 in `LICENSE.txt`. PxD bundles these files
as Twenty app public assets so production rendering has no font-CDN dependency.
