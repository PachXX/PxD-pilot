# PashX MAB Procurement

This private Twenty app is the metadata and presentation boundary for the single-workspace MAB procurement pilot.

The initial manifest installs the application, four approved object identities, eight command permission flags, and least-privilege Admin, Operator, Finance, and Viewer roles. Viewer is the default application role. The T3 Vendor PO spike adds only the technical header fields needed to prove authenticated, versioned, idempotent writes. Pricing formulas, VAT, discount, delivery, and final numbering policy remain blocked on the MAB Gate 0 field dictionary and acceptance packets.

Stable object, field, capability, command, error, and mapping identifiers come from `pashx-mab-contract`. Do not duplicate or regenerate them inside the app.
